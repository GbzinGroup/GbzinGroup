## 🧑🏽‍💻 Sobre mim

Sou desenvolvedor com interesse em diferentes áreas da tecnologia e gosto de transformar ideias em aplicações e projetos funcionais.

Meu foco está principalmente no desenvolvimento de **sites, plataformas Web, sistemas, automações, bots e aplicações**, explorando diferentes tecnologias conforme a necessidade de cada projeto.

Também utilizo o GitHub para desenvolver, organizar e compartilhar projetos, experimentar novas tecnologias e contribuir com o ecossistema de desenvolvimento.

> 💡 **Transformar uma ideia em código é apenas o começo. O objetivo é transformar o código em algo útil.**
